## Research Project
**Temporal Matching of CCTV, GPS and Written Evidence for Forensic Event Reconstruction**
Group: Vansh Rana, Anirudh Singh Aswal, Hardik Trivedi, Yash Shrivastava

The study tests whether representing each source's time uncertainty as an interval improves cross-source event matching compared with timestamp-only matching.

## Code and Data Availability
- **Public datasets (component testing only):** MOT16 – https://motchallenge.net/data/MOT16/ ; Microsoft GeoLife GPS Trajectories – https://www.microsoft.com/en-us/download/details.aspx?id=52367
- **Controlled scenarios:** scripted CCTV-style clips, simulated GPS traces and annotated narratives will be created by the authors and added to this repository.
- **Dashboard data:** simulated AQI data for six Indian cities (2025), included in the Excel file.
- No real CCTV footage or personal location data is used. Experiments are proposed work (Phase I); prototype code will be added as it is developed.
